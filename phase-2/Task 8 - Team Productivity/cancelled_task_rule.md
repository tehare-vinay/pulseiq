# Task 8 — Cancelled Task Rule

- Cancelled tasks are excluded from velocity.
- Cancelled tasks are excluded from cycle-time calculations.
- Cancelled tasks are excluded from the on-time delivery numerator and denominator.
- Cancelled tasks are reported separately as cancelled work.
- Cancelled tasks are never treated as completed deliveries.
- The source contains 898 cancelled tasks. None has both a start date and completion date, and none has both a completion date and due date.
- Open and cancelled tasks must not be counted as completed on-time deliveries.
